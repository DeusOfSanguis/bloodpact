# Пакт крови — перенос сайта с Tilda

Здесь лежит полная копия сайта **https://bloodpact-yufu.tilda.ws/** (11 страниц: главная + 10 разделов),
собранная заново в обычный HTML в том же оформлении: чёрный фон, белый текст, обложка на весь экран
с фоновым YouTube-видео и затемнением, линии-разделители между блоками.

Готовый сайт можно **сразу открыть/опубликовать** (папка `docs/`), а можно **перенести в Google Sites** —
ниже написано, как именно и какие есть ограничения.

---

## Сначала — главное про Google Sites

> «Скачанный сайт» в Google Sites загрузить нельзя. Ни с Tilda, ни даже экспорт другого сайта Google Sites —
> у Google Sites просто нет функции импорта HTML/ZIP.

Что Google Sites **умеет**:

| Способ | Что получится | Сколько времени |
|---|---|---|
| **1. Собрать заново стандартными блоками** (текст, картинки, YouTube, баннер) | Лучший результат: нормальная адаптивность, поиск по сайту, своё меню Google Sites | ~1–2 часа на 11 страниц (текст копируется из готовых файлов, жирный шрифт и списки сохраняются) |
| **2. Встроить готовую страницу по URL** («Вставка → Встроить → По URL») | Вид 1‑в‑1 как на Tilda, но страница показывается в рамке (iframe) фиксированной высоты — внутри рамки будет прокрутка | 10 минут, но сначала нужно опубликовать `docs/` на GitHub Pages (бесплатно, 1 минута — см. ниже) |
| **3. Вставить код страницы** («Вставка → Встроить → Код для встраивания») | То же, что п. 2, но без внешнего хостинга: код из папки `google-sites/` вставляется прямо в Google Sites | 15 минут |

Рекомендация: **вариант 1** для «настоящего» сайта на Google Sites, либо **вообще не использовать Google Sites,
а включить GitHub Pages** — это бесплатный хостинг, сайт из `docs/` будет выглядеть ровно как на Tilda, без плашки
«Made on Tilda» и без ограничений рамки. Варианты 2 и 3 — если нужно быстро и обязательно внутри Google Sites.

---

## Что в репозитории

```
content/            исходники — единственное место, где нужно править текст
  pages.json          список страниц, заголовки обложек, ID YouTube-видео, ссылки на картинки
  index.html …        текст каждой страницы (простой HTML: <h2>, <h3>, <p>, <ul>, <hr> = линия-разделитель)
  theme.css           оформление
build.py            сборка (Python 3, без зависимостей):  python3 build.py
docs/               ГОТОВЫЙ САЙТ — 11 страниц + assets/ (для GitHub Pages / любого хостинга)
docs/embed/         те же страницы без верхнего меню — для «Встроить по URL» в Google Sites
google-sites/       автономные HTML-файлы каждой страницы (все стили внутри) — для «Код для встраивания»
google-sites/ASSETS.md  шпаргалка: все страницы, ссылки на видео и картинки, код фонового видео
scripts/fetch_assets.py скачивает картинки с Tilda в docs/assets/img (сделайте это, пока Tilda-сайт жив!)
```

## Шаг 0 (важно): забрать картинки с Tilda

Сейчас страницы ссылаются на картинки прямо на CDN Tilda. Когда проект на Tilda удалится — картинки пропадут.
Поэтому один раз выполните в корне репозитория:

```bash
python3 scripts/fetch_assets.py   # скачает 8 файлов в docs/assets/img/
python3 build.py                  # пересоберёт сайт уже с локальными картинками
```

и закоммитьте `docs/assets/img/`. Если Python под рукой нет — скачайте файлы вручную по ссылкам из
`google-sites/ASSETS.md` и положите в `docs/assets/img/` под теми же именами.

## Публикация на GitHub Pages (нужна для варианта 2, полезна сама по себе)

1. На GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
2. Branch: ветка, в которой лежит этот код, папка **`/docs`** → **Save**.
3. Через минуту сайт будет по адресу **https://deusofsanguis.github.io/bloodpact/**
   (страницы: `.../law.html`, `.../squads.html` и т. д.; версии без меню: `.../embed/law.html`).

## Вариант 1 — собрать в Google Sites стандартными блоками (рекомендуется)

Названия пунктов приведены для русского интерфейса Google Sites, могут немного отличаться.

**А. Сайт и тема**

1. https://sites.google.com → **Создать** (пустой сайт). Название сайта: `Пакт крови` (или `yufu`).
2. Вкладка **Темы → Создать тему** («Custom»): шрифт заголовков и текста — *Roboto* или *Open Sans*
   (ближайшие к Tilda Sans); в разделе **Стили** задайте фон разделов чёрным `#000000`
   (текст Google Sites сам сделает белым). Основной цвет (кнопки/ссылки) можно поставить `#D40000`.
3. **Настройки (шестерёнка) → Навигация → Режим: Сверху**, цвет — прозрачный/тёмный.

**Б. Страницы** — вкладка **Страницы → +** создайте 11 страниц с такими названиями (это же будет меню):

`Главная страница`, `Демонический закон`, `Возвышение крови`, `Отряды`, `Шрамы`, `Пределы крови`,
`Битва крови`, `Территории`, `Поощрения`, `Рейтинг`, `Суд`.

**В. Каждая страница** (повторить 11 раз, по таблице в `google-sites/ASSETS.md`):

1. **Шапка**: наведите на заголовок → **Тип заголовка → Обложка** (самый высокий). **Изображение → Загрузить**
   → `docs/assets/img/cover.jpg`. В заголовке напишите текст обложки (например `Фракция демонов`),
   строкой выше мелким текстом — `YUFU`. Google Sites сам затемнит картинку под текст
   (если нет — **Изменить изображение → Настроить читаемость**).
2. **Видео**: **Вставка → YouTube** → вставьте ссылку из шпаргалки. Фоновым (автозапуск по кругу) видео
   в Google Sites не бывает; если хочется автозапуска — **Вставка → Встроить → Код для встраивания** и
   вставьте короткий код из раздела «Код фонового видео» в `ASSETS.md`.
3. **Текст**: откройте файл `google-sites/NN-….html` в браузере (двойной клик), выделите текст ниже обложки
   (или **Ctrl+A**), скопируйте (**Ctrl+C**), в Google Sites — **Вставка → Текстовое поле** и вставьте (**Ctrl+V**).
   Жирные подзаголовки и списки сохраняются. Между блоками текста ставьте **Вставка → Разделитель**
   (это аналог белых линий на Tilda).
4. **Фон раздела**: наведите на раздел слева → значок палитры → выберите стиль с чёрным фоном (из темы).
5. **Картинки** (только «Территории» и «Рейтинг»): **Вставка → Изображения → Загрузить** файлы из `docs/assets/img/`
   в тех местах, где они указаны в `ASSETS.md`. Фото чемпиона на «Рейтинге» можно обрезать в круг:
   выделить картинку → **Обрезать → форма «Круг»** (в новых версиях редактора).
6. **Опубликовать** (кнопка справа вверху) → адрес вида `sites.google.com/view/…`.

## Вариант 2 — встроить готовые страницы по URL

1. Включите GitHub Pages (см. выше).
2. В Google Sites создайте те же 11 страниц. На каждой: **Вставка → Встроить → По URL** → вставьте адрес
   версии без меню, например `https://deusofsanguis.github.io/bloodpact/embed/law.html` → **Вставить**.
3. Растяните блок на всю ширину и как можно выше (за нижний край). Всё, что не влезло, прокручивается внутри рамки.

## Вариант 3 — вставить код страницы

1. Откройте файл из папки `google-sites/`, например `02-law.html`, в текстовом редакторе, выделите всё, скопируйте.
2. В Google Sites: **Вставка → Встроить → вкладка «Код для встраивания»** → вставьте → **Далее → Вставить**.
3. Растяните блок. Картинки в этих файлах ведут на CDN Tilda; после включения GitHub Pages можно пересобрать
   их со своими ссылками: `python3 build.py --asset-base https://deusofsanguis.github.io/bloodpact/assets/img`.
   Если редактор откажется принимать слишком длинный код — используйте вариант 2.

---

## Как править тексты

Правьте файлы в `content/` (обычный HTML, структура очевидна), затем `python3 build.py` — обновятся и `docs/`,
и `google-sites/`. Заголовки обложек, видео и порядок меню — в `content/pages.json`.

Чтобы посмотреть сайт локально: `python3 -m http.server -d docs 8000` → http://localhost:8000/

## Что отличается от Tilda

- Шрифт: вместо фирменного Tilda Sans используется Inter (Google Fonts) с системным запасным шрифтом.
- Нет плашки «Made on Tilda».
- На телефонах вместо фонового видео показывается картинка обложки (так же делала и Tilda).
- Тексты перенесены дословно, включая авторскую орфографию.
