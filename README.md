# Пакт крови — сайт фракции демонов

Полная копия сайта **https://bloodpact-yufu.tilda.ws/** (11 страниц), собранная заново в обычный HTML
в том же оформлении: чёрный фон, белый текст, обложка на весь экран с фоновым YouTube-видео и затемнением,
линии-разделители. Адреса страниц те же, что были на Tilda: `/law/`, `/squads/`, `/ranking/` …

Хостинг — **GitHub Pages** (бесплатно), к нему можно подключить **свой домен** (тоже бесплатно, платите только
регистратору за сам домен).

---

## 1. Включить GitHub Pages (2 минуты, делает владелец репозитория)

Агент не может менять настройки репозитория, поэтому этот шаг — за вами.

**Вариант А — из основной ветки (рекомендуется):**

1. Слейте pull request с этой работой в `main` (кнопка **Merge pull request** на GitHub).
2. **Settings → Pages → Build and deployment → Source: Deploy from a branch**.
3. **Branch:** `main`, папка **`/docs`** → **Save**.

**Вариант Б — прямо из рабочей ветки (если хочется посмотреть сразу):** то же самое, но в пункте 3 выбрать
текущую рабочую ветку. Потом, после слияния, переключить на `main` там же.

Через 1–2 минуты сайт откроется по адресу **https://deusofsanguis.github.io/bloodpact/**
(страницы: `…/bloodpact/law/`, `…/bloodpact/squads/` и т. д.). Каждый новый коммит в `docs/` публикуется автоматически.

> Сразу после включения выполните шаг «Картинки» ниже — иначе после удаления проекта на Tilda пропадут фон обложки
> и картинки территорий.

---

## 2. Свой домен — да, подключается

GitHub Pages поддерживает свои домены бесплатно, с автоматическим HTTPS-сертификатом (Let's Encrypt).
Нужно только купить домен и прописать DNS-записи.

**Где купить.** Любой регистратор: для `.ru`/`.рф`/`.su` — reg.ru, nic.ru, timeweb, beget
(ориентировочно 200–1000 ₽/год, продление обычно дороже первого года); международные (`.com`, `.net`, `.site`)
у тех же регистраторов или у зарубежных (Namecheap, Porkbun — они могут не принимать российские карты).
Хостинг у регистратора покупать **не нужно**, только домен.

**Как подключить (после покупки):**

1. В панели регистратора откройте **управление DNS-записями** домена и добавьте:

   | Тип | Имя (хост) | Значение |
   |---|---|---|
   | A | `@` | `185.199.108.153` |
   | A | `@` | `185.199.109.153` |
   | A | `@` | `185.199.110.153` |
   | A | `@` | `185.199.111.153` |
   | AAAA (необязательно) | `@` | `2606:50c0:8000::153` |
   | AAAA (необязательно) | `@` | `2606:50c0:8001::153` |
   | AAAA (необязательно) | `@` | `2606:50c0:8002::153` |
   | AAAA (необязательно) | `@` | `2606:50c0:8003::153` |
   | CNAME | `www` | `deusofsanguis.github.io` |

   Если у регистратора уже есть A-запись `@` на его «заглушку» — удалите её.

2. В репозитории: **Settings → Pages → Custom domain** → введите домен (например `bloodpact.ru`) → **Save**.
   GitHub проверит DNS (может занять от минут до суток, обычно быстро) и сам положит файл `docs/CNAME` в ветку.
3. Когда появится галочка «DNS check successful» — включите **Enforce HTTPS**.
4. Чтобы файл `CNAME` не терялся при пересборке, пропишите домен и в конфиге сайта:
   `content/pages.json → "site" → "domain": "bloodpact.ru"`, затем `python3 build.py` (сборка сама создаст
   `docs/CNAME`; если поле пустое, существующий `CNAME` она не трогает). Могу сделать это за вас — просто
   напишите купленный домен.
5. Необязательно, но полезно: подтвердить домен на уровне аккаунта (**ваш профиль → Settings → Pages → Add a domain**,
   там дадут TXT-запись `_github-pages-challenge-deusofsanguis`) — это защита от перехвата домена.

После этого сайт будет открываться и по `https://bloodpact.ru/`, и по `https://www.bloodpact.ru/`
(`www` перенаправится на основной), а старый адрес `deusofsanguis.github.io/bloodpact` начнёт перенаправлять на домен.
Пока домен не подключён, в `content/pages.json` поле `"domain"` должно быть пустым —
иначе появится `docs/CNAME` и github.io начнёт редиректить на нерабочий адрес.

Ссылки на сайте идут от корня хоста (`/bloodpact/law/`), поэтому подстраницы не ломаются.

## 3. Картинки — забрать с Tilda, пока сайт там жив

Сейчас страницы ссылаются на картинки на CDN Tilda. Один раз выполните в корне репозитория:

```bash
python3 scripts/fetch_assets.py   # скачает 8 файлов в docs/assets/img/
python3 build.py                  # пересоберёт сайт уже с локальными картинками
git add -A && git commit -m "Картинки" && git push
```

Если Python под рукой нет — скачайте файлы вручную по ссылкам из `google-sites/ASSETS.md`
и положите в `docs/assets/img/` под теми же именами.

## Что в репозитории

```

  pages.json              список страниц, заголовки обложек, ID YouTube-видео, картинки, домен
  index.html, law.html …  текст каждой страницы (простой HTML: <h2>, <h3>, <p>, <ul>, <hr> = линия-разделитель)
```

## Как править тексты

Правьте файлы в `content/` (обычный HTML), затем `python3 build.py` → закоммитьте и запушьте `docs/`.
Заголовки обложек, видео на обложках, порядок меню и домен — в `content/pages.json`.
Посмотреть локально: `python3 -m http.server -d docs 8000` → http://localhost:8000/

Можно и без Python: править `docs/*/index.html` напрямую в веб-редакторе GitHub — но тогда правки надо дублировать
в `content/`, иначе следующая сборка их перезапишет.

## Если всё-таки понадобится Google Sites

Google Sites не умеет импортировать готовый сайт (ни HTML, ни ZIP). Возможны только:
**Вставка → Встроить → По URL** (адрес страницы без меню, например
`https://deusofsanguis.github.io/bloodpact/embed/law.html`) или **Код для встраивания** (файлы из `google-sites/`).
В обоих случаях страница показывается в рамке с прокруткой. Для «нативного» сайта на Google Sites текст удобно
копировать из файлов `google-sites/NN-*.html`, открытых в браузере (жирный шрифт и списки сохраняются),
все ссылки — в `google-sites/ASSETS.md`.

## Что отличается от Tilda

- Шрифт: вместо фирменного Tilda Sans — Inter (Google Fonts) с системным запасным шрифтом.
- Нет плашки «Made on Tilda».
- На телефонах вместо фонового видео показывается картинка обложки (так делала и Tilda).
- Тексты перенесены дословно, включая авторскую орфографию.
